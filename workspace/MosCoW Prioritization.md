## MoSCoW Requirement Prioritization

## Objective

To identify and prioritize the requirements of your assigned project using the MoSCoW Requirement Prioritization Technique.

## Questions / Tasks

Q1. Identify 15-20 important requirements for your project.

The requirements should include a suitable combination of:

- Functional requirements

- Non-functional requirements

- User/stakeholder requirements

- System requirements

Write each requirement clearly and unambiguously.

Q2. Prioritize each requirement using the MoSCoW technique:

- M – Must Have: Essential requirement

- S – Should Have: Important but not essential

- C – Could Have: Desirable but optional

- W – Won’t Have: Not included in the current version

Q3. Give a one-line justification for the priority assigned to each requirement.
